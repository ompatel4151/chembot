Batch Questions
Run a list of questions through ChemBot
← Dashboard

1. Choose a question file

A CSV file with one question per row, in a column whose heading contains "question" (or in the first column). From Excel or Google Sheets: File → Save As / Download → CSV. Each question is answered on its own, with no chat history, and none of them are added to the student analytics.

2. Run and export

Keep this tab open while it runs. Answers are saved in this browser as they arrive, so if the tab closes or the run stops, choose the same file again and press Start to continue where it left off.
